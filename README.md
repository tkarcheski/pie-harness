# PIE Harness — Personal Income Engine

Reusable local-first infrastructure for operating and maintaining income-generating workflows.

## Implementation status

This scaffold contains architecture documentation, versioned contracts, synthetic fixtures, and standalone checks. Runtime execution, dashboards, adapters, account access, and economic reporting are planned.

Run `node --test tests/contracts.test.mjs` with Node.js 22 or later. The checks run without dependencies, production credentials, or external services.
